# 阶段 6：部署到腾讯云指南

服务器 IP：`162.14.78.163`

本指南提供了详细的操作步骤。假定您的服务器操作系统为 **Ubuntu 20.04/22.04**，如果您使用的是 CentOS/Rocky Linux，请将 `apt` 替换为 `yum`/`dnf` 即可。

## 6.1 服务器环境准备 (Python3-venv, Nginx, Certbot)

SSH 登录到您的腾讯云服务器：
```bash
ssh ubuntu@162.14.78.163
# 若是用 root 用户登录，则直接使用 ssh root@162.14.78.163
```

更新软件包并安装必需的基础环境：
```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip nginx certbot python3-certbot-nginx
```

## 6.2 上传代码，安装 Python 依赖 (venv)

在**本地电脑**的终端上，使用 `rsync` 或者 `scp` 将代码上传到服务器（也可以在服务器上使用 `git pull`拉取）：
```bash
# 进入本地代码根目录
cd /Users/wangyu/code/app

# 同步代码到云服务器（以放到 /home/ubuntu/app 为例）
rsync -avz \
--exclude node_modules \
--exclude .git \
--exclude __pycache__ \
--exclude venv \
./ tencent-prod:/home/ubuntu/app/
```
注意到此处 tencent-pro 是一个别名，就是你在 server.md 里面设置的

回到**云服务器终端**，创建并激活虚拟环境，然后安装依赖：
```bash
cd /home/ubuntu/app/backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## 6.3 配置 `.env` 文件

在服务器的 `backend` 目录下创建 `.env` 文件：
```bash
cd /home/ubuntu/app/backend
nano .env
```

填入相关环境变量配置（请替换为您实际的基础校验密钥及腾讯云 COS 参数）：
```ini
SECRET_KEY=填入一个随机的长字符串
COS_SECRET_ID=你的腾讯云COS_SECRET_ID
COS_SECRET_KEY=你的腾讯云COS_SECRET_KEY
COS_REGION=ap-guangzhou
COS_BUCKET=你的存储桶名称
DATABASE_URL=sqlite:///./app.db
```
保存并退出（nano 下按 `Ctrl+O`, `Enter`, `Ctrl+X`）。


## 6.5 创建初始教师账号

继续在虚拟环境内运行管理员生成脚本：
```bash
python create_admin.py
```
根据提示输入管理员用户名和密码，用于之后登录系统后台。

## 6.6 配置 systemd 服务

为了让 FastAPI 在服务器重启后自动启动且保持常驻运行，我们需要使用 `systemd`。

在服务器上创建并编辑服务文件：
```bash
sudo nano /etc/systemd/system/app.service
```

填入以下内容（如果代码放在了其他路径，请相应修改 `WorkingDirectory` 和执行路径）：
```ini
[Unit]
Description=app FastAPI Backend Service
After=network.target

[Service]
User=ubuntu
# 若以root运行，请改为 User=root
WorkingDirectory=/home/ubuntu/app/backend
Environment="PATH=/home/ubuntu/app/backend/venv/bin"
ExecStart=/home/ubuntu/app/backend/venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
Restart=always

[Install]
WantedBy=multi-user.target
```

启动并设置开机自启：
```bash
sudo systemctl daemon-reload
sudo systemctl start app
sudo systemctl enable app
sudo systemctl status app  # 查看运行状态是否为 active (running)
```

## 6.7 构建前端产物放入服务器

回到您的**本地电脑**终端，进行前端打包。如果您的前端请求使用相对路径 `/api`（利用 Nginx 代理），此处直接构建即可。如果配死了 BaseURL，请确保修改为线上的 `/api`：

```bash
cd /Users/wangyu/code/app/frontend
npm install
npm run build
```

通过 rsync 将构建产物 `dist` 目录传到服务器：
```bash
rsync -avz dist/ tencent-prod:/home/ubuntu/app/frontend/
```

## 6.8 配置 Nginx 反向代理
 

这里要格外注意，千万不要自作聪明修改 /etc 目录的权限，要不然就直接爆炸了。


回到**云服务器终端**。在 Nginx 中配置静态网页托管及接口代理：
```bash
sudo nano /etc/nginx/sites-available/app
```

写入以下配置：
```nginx
server {
    listen 80;
    server_name 162.14.78.163; # 此处填入IP，如果有绑定域名可填入域名

    # 重点：修改 Nginx 允许的最大上传限制为 50MB
    client_max_body_size 50M;

    # 部署前端静态页面
    location / {
        root /home/ubuntu/app/frontend/dist;
        index index.html;
        # 支持 Vue Router 的 History 模式
        try_files $uri $uri/ /index.html;
    }

    # 代理后端 API
    location /api/ {
        proxy_pass http://127.0.0.1:8000/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

启用 Nginx 配置：
```bash
# 删除系统默认的配置
sudo rm /etc/nginx/sites-enabled/default
# 软链启用我们的配置
sudo ln -s /etc/nginx/sites-available/app /etc/nginx/sites-enabled/

# 测试配置文件是否有错误
sudo nginx -t

# 重新加载生效
sudo systemctl reload nginx
```

## 6.9 申请 HTTPS 证书（可选，需要域名）

如果您配置了域名（例如 `submit.yourdomain.com`，需先在 DNS 服务商处解析 A 记录到 162.14.78.163），并把上一条 Nginx 中的 `server_name` 改为了该域名，请运行：
```bash
sudo certbot --nginx -d submit.yourdomain.com
```
按照终端的步骤提示完成即可，Certbot 会自动帮你配置 Nginx 开启 HTTPS 和重定向。

如果只有 IP，可以暂时跳过，通过 HTTP 访问，但请确保在云防火墙/安全组开放了 80（和 443）端口。
