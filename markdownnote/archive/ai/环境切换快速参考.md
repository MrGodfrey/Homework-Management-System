# 🎯 环境切换快速参考

## 当前状态 ✅
- **当前环境**：DEV（开发环境）
- **文件路径前缀**：`dev_env/`
- **配置文件**：[backend/.env](../backend/.env)

---

## 三种切换方法

### 🌟 方法 1：使用脚本（最简单）

```bash
# 切换到 DEV
./switch_env.sh dev

# 切换到 PROD
./switch_env.sh prod

# 查看当前环境
./switch_env.sh status

# 交互式菜单
./switch_env.sh
```

### 📝 方法 2：编辑 .env 文件

编辑 `backend/.env`：
```bash
# 改为 DEV
ENV=DEV

# 或改为 PROD
ENV=PROD
```

### ⚡ 方法 3：临时设置（测试用）

```bash
# 临时 DEV
ENV=DEV python3 start_local_test.py

# 临时 PROD
ENV=PROD python3 start_local_test.py
```

---

## 验证命令

```bash
# 快速查看
./switch_env.sh status

# Python 查看
cd backend && python3 -c "from app.config import settings; print(settings.ENV)"
```

---

## 重启服务

切换环境后必须重启：
```bash
pkill -f uvicorn && python3 start_local_test.py
```

---

## 文件路径对照表

| 环境 | ENV 值 | COS 路径前缀 | 用途 |
|------|--------|--------------|------|
| 开发 | `DEV` | `dev_env/` | 本地测试、功能开发 |
| 生产 | `PROD` | `prod_env/` | 线上服务、真实数据 |

### 示例路径

**DEV 环境**：
```
dev_env/submissions/1/20230001/20260313_181530_a1b2c3d4_homework.pdf
```

**PROD 环境**：
```
prod_env/submissions/1/20230001/20260313_181530_a1b2c3d4_homework.pdf
```
