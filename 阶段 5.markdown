# 阶段 5：前端开发 - 报告

- `pinia` 鉴权状态管理模块（`stores/auth.js`）。
- 脚手架搭建了所有的前后端页面组件（`Login.vue`, `Dashboard.vue`, `AssignmentList.vue` 等）。
- 编写了边缘场景的核心测试脚本（使用 Vitest 进行 401 及鉴权拦截器测试）。
